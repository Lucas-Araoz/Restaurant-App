# 🍽️ Mobile Restaurant Menu Application

A sleek, responsive, and intuitive mobile-first restaurant menu interface designed for seamless food ordering. This project focuses on high performance, semantic structure, and a clean user experience using native web technologies.

---

## ✨ Features

* **Mobile-First Design:** Optimized for mobile viewports, simulating a native app feel with smooth transitions.
* **Dynamic Filtering:** Fast and seamless category switching (Burgers, Pizzas, Drinks) using optimized array methods.
* **Real-time Cart Management:** Live updating cart badge, itemized list generation, and precise total price calculation.
* **Modern Aesthetics:** Clean UI featuring beautiful imagery, custom scrollbars, and a slide-up checkout sheet.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic architecture for improved accessibility and structure.
* **CSS3:** Modern layouts powered by Flexbox, featuring CSS Custom Properties (variables) for effortless theme switching.
* **JavaScript (ES6+):** Pure Vanilla JS for DOM manipulation, state tracking, and dynamic data rendering—zero external dependencies.

---

## 🚀 Getting Started

### Prerequisites
To view and test this project locally, you only need a modern web browser. Using a code editor like **Visual Studio Code** with the **Live Server** extension is highly recommended for the best experience.

### Installation & Running

1. Clone or download this repository to your local machine.
2. Ensure all three core files (`index.html`, `styles.css`, and `app.js`) are placed within the same directory.
3. Open the directory in your code editor.
4. Launch `index.html` using a local server setup (e.g., click **"Go Live"** in VS Code).
5. Switch your browser view to a mobile device emulation mode (F12 inspect -> Toggle Device Toolbar) for the intended experience.
